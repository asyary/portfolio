# asyary@portfolio:~$

A terminal-style portfolio website :D

## Features

- **Terminal UI Design** - Terminal-esque aesthetic using Bootstrap
- **Tab Navigation** - Switch between About, Projects, and Contact sections
- **Responsive Layout** - Mobile-friendly design (kinda)

## Sections

- **About** - Background in ethical hacking, backend development, and current projects
- **Projects** - Featured security assessments and bug hunting experiences
- **Contact** - Links to email, GitHub, LinkedIn, Medium, and PGP key

## Tech Stack

- HTML5
- Bootstrap 5.3.8
- CSS3
- Vanilla JavaScript

## Quick Start

1. Clone the repository
2. Open `index.html` in your browser
3. Navigate using the tab buttons
